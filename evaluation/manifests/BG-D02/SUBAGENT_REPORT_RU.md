# BG-D02 — отчёт параллельного исполнителя

## Объём и граница

Работа выполнена только в изолированной рабочей копии BG-D02. Общие файлы,
основная рабочая копия, другие фикстуры, официальное или оцениваемое выполнение,
живая модель, Chromium, браузер, MCP, Claude, commit и push не затрагивались.
Внешняя память и приватные ресурсы не читались. Новая сырая трасса не создавалась:
владелец заменил вложенный Codex CLI на штатного параллельного исполнителя.

## Гипотеза

Первый видимый тест останавливался до проверки поведения, потому что Node 22
предоставляет `globalThis.navigator` через свойство без доступного присваивания.
Установка jsdom-глобалов через дескрипторы должна устранить только несовместимость
тестовой обвязки и не менять контракт кандидатов.

## Обнаруженный и удалённый эксперимент

До этой задачи в одной рабочей копии почти одновременно появились две несовместимые
семьи BG-D02. Полноценная TypeScript-фикстура описывала табло отправки посылок и
содержала `candidate-a`/`candidate-b`. Упрощённый MJS-прототип описывал счётчик и
содержал `preserving`/`false-green`. Это давало два описания поведения, четыре
кандидата и две семьи манифестов вместо одной фикстуры и двух кандидатов.

Первоначальная диагностика MJS-прототипа сохранена как отрицательный эксперимент:

1. системный `node --test tests/BG-D02-visible.test.mjs` использовал Node `18.16.1`
   и остановился с `ERR_REQUIRE_ESM` до выполнения тестов;
2. на замороженном Node `22.22.3` прямое присваивание `globalThis.navigator`
   оказалось недопустимым;
3. после локального descriptor-исправления оба теста показали `0` вместо `1`, потому
   что прототип не подключал `.value` к React-рендеру через `useSignals()`;
4. после локальной коррекции MJS-вариант прошёл доступные проверки, но оставался
   конкурирующей, методологически неполной семьёй.

Координатор явно выбрал TypeScript `ParcelDispatchBoard` и отклонил MJS
`QueueBatchCounter` как удалённый прототип. Удалены ровно восемь разрешённых путей:

- `evaluation/behavior-specs/BG-D02-queued-batched-updates.md`;
- `candidates/BG-D02/preserving/QueueBatchCounter.mjs`;
- `candidates/BG-D02/false-green/QueueBatchCounter.mjs`;
- `evaluation/arm-visible/BG-D02/contract.mjs`;
- `evaluation/verifier-only/BG-D02/oracle.mjs`;
- `evaluation/manifests/BG-D02/candidates.json`;
- `tests/BG-D02-visible.test.mjs`;
- `scripts/BG-D02-denied-oracle-access.mjs`.

## Критерии выбора

TypeScript-вариант сохранён, потому что он единственный образует полный согласованный
пакет из двуязычного behavior-first описания, freeze-записи, двух кандидатов, пяти
общих видимых утверждений, fail-closed проверки единицы, скрытого канонического
оценщика, четырёх воспроизводимых манифестов и взаимного физического запрета доступа.
Он также проверяет полный сценарий из девяти действий и сохраняет единственный
посеянный дефект накопления двух записей. MJS-вариант проверял только сокращённый
счётчик, не входил в основной freeze-пакет и дублировал идентификатор BG-D02 с другой
предметной областью.

В двух сохранённых behavior-файлах дополнительно удалены шесть пробелов Markdown в
конце строк. Текст и семантика не изменились; соответствующие SHA-256 в
`BG-D02_FREEZE.yaml` обновлены до
`806c0ef2e6968ab5503b34275abaa545c3733816a62cb4b5820cb4dc3c579490` и
`faf76bc563e2948262e9fe9fbc5d835fce02facfeed1ce5abe010d5ddb3aed49`.
Статус freeze не менялся.

## Проверки после удаления

Стандартная компиляция:

```text
PATH=<redacted-local-path> npm run compile
```

прошла без ошибок: `tsc -p tsconfig.json --noEmit`.

Полная fixture-specific проверка:

```text
PATH=<redacted-local-path> node scripts/BG-D02-verify.mjs
```

завершилась `BG-D02_VERIFICATION_PASSED`:

- компиляция D02 TypeScript прошла;
- пять видимых утверждений и fail-closed контракт единицы прошли `6/6`;
- скрытая самопроверка прошла `2/2`: `candidate-a` принят, `candidate-b` отклонён
  на первом `queue-1x2`;
- четыре package-манифеста совпали;
- все `4/4` операции доступа ветки оценки к verifier-only запрещены и дают
  неразличимые ошибки;
- все `3/3` операции доступа оценщика к кандидатам запрещены.

Отдельная команда манифестов:

```text
PATH=<redacted-local-path> node scripts/BG-D02-manifests.mjs
```

повторно вернула `BG-D02_MANIFESTS_VERIFIED`. Независимая сверка пересчитала
SHA-256 обоих кандидатов после тестов и получила значения из манифестов:
`BG-D02_CANDIDATE_IMMUTABILITY_VERIFIED`.

Финальный локальный аудит пересчитал два behavior-хеша, проверил JSDoc у каждого
экспортируемого объявления в десяти TypeScript-модулях, разрешённость всех 25 путей
из `git status`, обычный `git diff --check` и `git diff --no-index --check` для
каждого untracked-файла. Итог:
`BG-D02_FINAL_AUDIT_PASSED paths=25 ts_modules=10`.

## Ограничения и последующая интеграция

Shared registry, общий changelog, индексы происхождения/траекторий, общие checksum,
boundary и проекции документации не менялись. Координатору нужно отдельно записать
удалённый MJS-эксперимент в общем Improvement Changelog, согласовать provenance и
включить только сохранённую TypeScript-семью в общие реестры и контрольные суммы.
Это не разрешает official/scored run, commit или push.

## Итог

В D02 осталась одна согласованная TypeScript-фикстура и ровно два immutable
кандидата. Compile, видимые и скрытые проверки, хеши, неизменность кандидатов,
взаимная физическая изоляция, JSDoc, scope и diff-проверки проходят. MJS-вариант
сохранён в отчёте как честно удалённый эксперимент, но его файлы больше не входят в
рабочую копию.
