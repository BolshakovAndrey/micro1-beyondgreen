# BG-H03 — отчёт дочернего агента по реализации

## Результат

Фикстура `BG-H03` реализована строго по одобренной заморозке класса устойчивости
идентичности. Публичная часть содержит типизированный контракт, минимальную React/
jsdom-обвязку, проекцию DOM и четыре намеренно неполные видимые проверки. Созданы
ровно два нейтрально названных кандидата `candidate-a` и `candidate-b`; их
соответствие правильному и ложно-зелёному поведению записано только в закрытом от
оцениваемых ветвей файле `evaluation/verifier-only/BG-H03/ground-truth.json`.

Закрытый пакет проверяющего содержит канонический сценарий из восьми наблюдений,
точные сравнения ссылок `SelectionHandle`, счётчик подключений, самопроверку и
обратную проверку запрета чтения кандидатских байтов. Публичная permission-проба —
проверка разрешений отдельного процесса Node — доказывает запрет чтения,
перечисления, проверки существования и получения метаданных закрытого пакета.
Предварительных подсказок проверяющего не было: `K=0`.

## Точные команды, ошибки и исправления

1. `node --version && npm --version && npm run compile` — активный системный Node
   сообщил `v18.16.1`, npm `9.5.1`; компиляция прошла. Этот runtime не использовался
   для выполнения TypeScript-тестов.
2. `"$NVM_BIN/node" "$NVM_BIN/npm" run compile && "$NVM_BIN/node" --test evaluation/arm-visible/BG-H03/visible.test.ts evaluation/verifier-only/BG-H03/self-check.test.ts evaluation/arm-visible/BG-H04/visible.test.ts evaluation/verifier-only/BG-H04/self-check.test.ts` — первая попытка: компиляция прошла, общий результат `11/12`. Все шесть проверок H03 прошли; единственный сбой относился к локальной H04.
3. После локального исправления H04 повторена та же команда — компиляция прошла,
   `12/12` тестов прошли. Для H03 это четыре видимые проверки и две проверки
   закрытого эталона: правильный кандидат принят, ложно-зелёный отклонён на первом
   постороннем изменении заметки.
4. `"$NVM_BIN/node" --permission --allow-fs-read=evaluation/arm-visible/BG-H03 evaluation/arm-visible/BG-H03/denied-probe.mjs` — `allDenied=true`, четыре операции запрещены.
5. `"$NVM_BIN/node" --permission --allow-fs-read=evaluation/verifier-only/BG-H03 evaluation/verifier-only/BG-H03/evaluator-denied-probe.mjs` — `allDenied=true`, три операции запрещены.
6. По уточнению координатора выполнено `zsh -lic 'node --version'` — получено
   `v22.22.3`. Затем через тот же login shell выполнены `npm run compile` и четыре
   перечисленных fixture-local тестовых файла: компиляция прошла, `12/12` прошли.
   Login shell выдал не влияющие на команды предупреждения `monitor` и
   `gitstatus failed to initialize`; exit code проверки остался `0`.
7. Четыре permission-пробы повторены через `zsh -lic`; для H03 снова получены
   `allDenied=true` с четырьмя и тремя запрещёнными операциями соответственно.
8. После локального усиления финального наблюдения H04 весь набор через `zsh -lic`
   повторён ещё раз: компиляция, `12/12` и все четыре permission-пробы прошли.

Перед фиксацией хешей удалены раскрывающие смысл комментарии из кандидатских файлов:
названия и пояснения кандидатов теперь нейтральны, а mapping — соответствие истине —
остаётся только в `verifier-only`. Это исправление границы, а не изменение поведения.

## Границы и запрос координатору

Общие registry/tasks, `package.json`, package scripts, общий checksum index,
integration tests, документы и чужие фикстуры не менялись. Координатору необходимо
отдельно зарегистрировать H03 в shared orchestration, добавить общий checksum index
и интеграционные проверки. Официальный или оцениваемый запуск, unblinding, модель,
Claude, Chromium, browser/private MCP, приватные данные, общий preflight и push не
выполнялись. Внутренние необработанные события дочернего агента не заявляются как
экспортированная трасса.
