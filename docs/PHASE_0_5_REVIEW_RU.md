# Карточка результата после фиксации Phase 0.5

Phase 0.5 зафиксирована без начала разработки продукта. Условие владельца выполнено:
последняя Chromium-проверка прошла correctness и воспроизводимость, а отсутствие
CPU-ускорения честно раскрыто и не используется как claim.

## Решение владельца о вложенном CLI

Владелец решил не блокировать Phase 0.5 из-за вложенного запуска командного клиента
Codex внутри desktop-приложения:

`«Я не вижу смысла в этом запуске, мы и так работаем через Sol сейчас, когда я отправляю эти запросы. Возможно, это не работает при вызове из приложения ChatGPT на Mac, но это и не важно, потому что запросы проходят и ответы приходят. Я хочу скипнуть эту проверку и, если других препятствий нет, закрыть эту часть»`.

Это исключение действует только для Phase 0.5. Два неудачных запуска `codex exec`
не переименованы в успех, и работа этого пути не доказана. Работа Sol, наблюдаемая
владельцем в приложении, — контекст владельца, а не доказательство для submission.
В обычном терминале `codex exec` остаётся необязательным вариантом с запретом
автоматического повтора; его практическая проверка отложена. Проверенным способом
повторить уже записанный результат остаётся offline replay — локальное
воспроизведение событий без сети и нового вызова модели. Оно доказывает
повторяемость записи, но не живую работу модели.

## Что было разрешено

Владелец ранее одобрил измерительную проверку вопросом
`«Одобряете технический Phase 0.5 spike с подписочным codex exec/gpt-5.6-sol без API, одним вызовом без повторов и сценарием на 300 карточек?»` и выбрал
`«Одобряю spike (Recommended)»`. Отдельно были одобрены один исправленный аудит
лицензий, добавление `MIT-0` и `BlueOak-1.0.0`, обязательный
`THIRD_PARTY_NOTICES.md`, один финальный аудит и один безопасный диагностический
повтор модели. Эти разрешения не распространяются на продукт, зачётные данные,
официальный benchmark, commit или push.

## Что прошло

- Точные версии зависимостей записаны в lockfile; `npm ci --ignore-scripts`
  воспроизводимо установил 54 пакета зависимостей и сообщил 0 уязвимостей.
- Финальный аудит лицензий прошёл 54/54. Стабильный хеш состава пакетов:
  `68519a270c035c5cb2c8cb92f6d27b44ed47958a4c31b134bcbdb7f4a364ef18`.
  Хеш lockfile:
  `1beb2987e3e0654cb525b80c2f97a2f6577f92399e8a78fcd8eb9f9ab6487d4c`.
  Создан воспроизводимый `THIRD_PARTY_NOTICES.md` для лицензий сторонних пакетов.
- Зафиксированы Node `22.22.3`, npm `10.9.8`, TypeScript `5.9.3`, React/ReactDOM
  `19.2.8`, jsdom `30.0.1`, Zod `4.5.2` и signals-пакет
  `@preact/signals-react@3.12.0` с лицензией MIT. Их совместимость и десять требуемых
  классов поведения прошли 11/11 локальных проверок.
- Парсер JSONL, проверка схемы, запрет автоматического повтора, обработка timeout и
  offline replay прошли локальные тесты без нового вызова модели.
- Независимый музейный Chromium-стенд прошёл барьер правильности в
  `Chrome/152.0.7977.64`. После каждого действия совпали все 300 значений, выбранные
  ID, журнал действий и его хеш; сброс вернул исходное состояние. Ошибок console —
  0, необработанных исключений — 0.
- Финальный браузерный отчёт содержит 5 прогревов и 30 измерений для каждой ветки,
  всего 60 отдельных измерений в заранее установленном чередующемся порядке.

## Что измерено

Для каждой измеряемой попытки основная доска отрисовывалась 8 раз в обеих ветках.
Базовая ветка вызвала 2400 отрисовок карточек, улучшенная — 1900. Это уменьшение на
500 вызовов, или 20,83%. Этот вывод разрешён, потому что поведение полностью совпало.

Средняя дельта процессорной работы CDP `TaskDuration` была 4,7071 мс у базовой ветки
и 5,0037 мс у улучшенной. Разброс заметен: коэффициент вариации 0,3402 и 0,3612.
Поэтому ускорение CPU не заявляется. React Profiler не использовался. Безопасное
описание среды: Darwin 24, arm64, 10 логических ядер, память в диапазоне 16–31 GiB;
имя компьютера, пользователь, пути и идентификаторы не записаны.

Отчёт измерений: `artifacts/phase-0.5-chromium-spike.json`. Его SHA-256:
`688baad33e10966944f8d73dd09e03af1f7aa4301cd2d2c66d7efe1b03bf6b41`.

## Что не прошло и что пошло не идеально

- Два отдельно разрешённых запуска `codex exec --model gpt-5.6-sol` завершились
  exit 1 без корректного финального JSON. Первый получил безопасный код
  `MODEL_TRANSPORT_FAILURE`, второй — категорию `unknown`. Автоматических повторов и
  замены модели не было. Сырой stderr не сохранялся и не показывался.
- Безопасная диагностика `codex doctor` стабильно сообщала `DNS_RESOLUTION`, хотя
  отдельная проверка публичных `chatgpt.com`, `auth.openai.com` и `api.openai.com`
  прошла DNS и TLS. Причина live-отказов не доказана. Владелец явно разрешил пройти
  этот барьер только для Phase 0.5; CLI остаётся непроверенным.
- Историческая первая команда аудита лицензий была неверной и завершилась
  `EQUERYNODEPTYPE`. После отдельного разрешения локальный сканер сначала нашёл три
  ещё не разрешённые лицензии; владелец добавил только `MIT-0` и
  `BlueOak-1.0.0`, после чего единственный финальный аудит прошёл 54/54.
- Первый Chromium-прогон прошёл по поведению и собрал показатели, но отчёт сохранил
  только сводку, а утверждённый контракт требовал каждое отдельное измерение. После
  добавления проверки выполнен один повтор только для упаковки evidence. В нём не
  менялись N=300, действия, порядок, пять прогревов или 30 измерений на ветку. Второй
  отчёт содержит все 60 измерений. Это один instrumentation/evidence retry, а не
  подбор параметров по результату.
- В stack harness был один исправленный тестовый повтор из-за read-only
  `globalThis.navigator`. В коде сканера лицензий тесты один раз выявили две ошибки до
  запуска разрешённого аудита. Все эти исправления сохранены в истории честно.

## Что не делалось

Не создавались продуктовый код, зачётные fixtures/candidates/oracles, официальный
benchmark, repair demo или скрытые ответы. Chromium-стенд использует только
независимо написанную нейтральную музейную доску и не основан на приватном коде,
названиях, структурах, layout или данных. Новых model/Codex-вызовов после решения
владельца не было. Commit и push не выполнялись.

## Финальные проверки

Основные тесты прошли 16/16, stack — 11/11, model-adapter/offline replay — 6/6,
защита CLI — 3/3, защита doctor — 4/4, защита сетевой матрицы — 3/3, Chromium
harness — 4/4. Повторный аудит лицензий прошёл 54/54 с неизменными хешами состава,
lockfile, содержимого отчёта и notices. YAML, Markdown, privacy scan и
`git diff --check` прошли.

Safe control preflight вернул `READY_FOR_CLEAN_BRANCH`, implementation preflight —
`READY_FOR_IMPLEMENTATION`; два прежних placeholder-error сняты. Остались ожидаемое
предупреждение о незакоммиченном рабочем дереве и четыре прежних бинарных файла,
которые требуют отдельной человеческой проверки перед submission. Этот автоматический
PASS не является разрешением писать продукт и не снимает trace/provenance gates.

## Итог фиксации и оставшиеся запреты

Phase 0.5 **зафиксирована с явным исключением для вложенного CLI**: лицензии, стек,
offline replay и Chromium correctness прошли;
уменьшение числа отрисовок доказано; ускорение CPU не доказано; живой вложенный
`codex exec` остаётся отложенным и непроверенным.

Условное решение владельца было: закрыть эту часть, если после Chromium не останется
других препятствий. Координатор подтвердил 60 измерений, неизменные N=300 и порядок,
полную правильность и одинаковые digests, render counts 2400/1900, CPU
4,7071/5,0037 мс и PASS тестов/`git diff --check`. Условие выполнено.

Для product implementation всё ещё нужны: eligible capture, автоматическая и
человеческая проверка текущей Phase 0.5 траектории; отдельное явное разрешение
владельца на product work; а перед кодом конкретной fixture — independently authored
behavior prose, public provenance и их freeze; также нужен чистый Git-checkpoint,
который сейчас нельзя создать, потому что commit не разрешён. Scored
fixtures/candidates/oracles, official benchmark, commit и push по-прежнему запрещены.
