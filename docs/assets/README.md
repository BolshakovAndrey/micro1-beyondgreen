# README presentation assets

These assets were added after the original public release to explain BeyondGreen.
They are presentation material, not scored evaluation evidence.

- `micro1-participation.png` is a rendered page of `Participants.pdf`, supplied by
  the repository owner for this presentation. The certificate content was not
  altered. It records participation in the micro1 Frontier Engineering Challenge
  2026, dated September 10, 2026; it does not establish an award or benchmark result.
- `workflow.svg` and `workflow-ru.svg` are original, self-contained diagrams created
  for this README from the existing architecture and evaluation documentation.
  They use no external scripts, fonts, or image resources.
